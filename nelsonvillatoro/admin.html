How to Use This Form

This form helps you create new blog posts for your website. Follow these steps:

  1. Fill in all the required fields
  2. Use the rich text editor to format your content
  3. Add tags relevant to your post
  4. Click "Save Blog Post" to generate the JSON
  5. Copy the generated JSON and add it to your blog.json file

To create a featured image, add the image to the assets/images/blog/ directory and reference it in the Featured Image field.
